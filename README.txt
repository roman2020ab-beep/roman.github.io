Изменения:
- После правильного ответа в тесте теперь появляется кнопка «Далее», чтобы можно было прочитать сообщение.

- Глава 8: два слова уже стоят в предложении, остальные слова представлены отдельными перетаскиваемыми карточками; на телефоне есть и запасной вариант «нажать слово → нажать место».
